# Last Knights Public Mechanics Sources

Reference log for external mechanics signals used by the balancing monitor.

## Usage policy

- Treat these as **reference-only** signals for the `referenceLastKnights` baseline.
- Keep `royalArmies` as the shipping decision baseline.
- Prefer sources that are clearly about **The Last Knights** (same title/game).
- Mark uncertain or cross-game sources as low confidence.

## Accepted reference sources

### 1) The Last Knights (Fandom)
- URL: `https://lastknights.fandom.com/wiki/The_Last_Knights`
- Confidence: **medium**
- Signals used:
  - Officer rank progression
  - Soldier individuality (unit-level growth)
  - Battle-earned experience
  - Large-scale alliance/army scaling

### 2) The Last Knights listing (NewRPG)
- URL: `https://newrpg.com/browser-games/the-last-knights/`
- Confidence: **low-medium**
- Signals used:
  - Barracks-based recruitment loop
  - Income/wage pressure as army size grows
  - Experience/level-up pacing pressure

### 3) The Last Knights official site status page
- URL: `https://lastknights.com/`
- Confidence: **low** (limited content while service unavailable)
- Signals used:
  - Canonical game identity confirmation only

## Rejected / do-not-use sources

- Any posts/pages about **Knights and Merchants**, **Lands & Lords**, CK3 men-at-arms proposals, or other similarly named titles.
- Event optimization guides for unrelated games (e.g., Last War unit pipelines).

## Update process

When adding new external sources:
1. Confirm same game identity first.
2. Add source URL and confidence rating.
3. Record extracted mechanics signals.
4. If uncertain, classify as rejected until verified.
